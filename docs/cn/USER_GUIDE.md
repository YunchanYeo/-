# 用户运营指南 (CN)

## 1) 适用对象

- 运营、客服、后台管理员
- 仅覆盖页面操作，不涉及代码修改

## 2) 管理后台主要操作

### 订单/发货

- 在 `订单与发货` 页面更新订单状态
- 填写物流公司与运单号
- 查看物流轨迹

### Excel 批量处理

- `导出 Excel`：导出订单数据
- `导入 Excel`：批量更新订单信息
- `导入预检(Dry-run)`：只校验，不落库
- `重试失败项`：自动重试失败记录
- `导出失败项Excel`：导出失败明细

### 订单隐藏/恢复（仅管理员视图）

- 勾选后执行 `选中隐藏` / `选中恢复`
- 支持 `查看已隐藏`、`恢复全部`
- 注意：不删除用户订单，不删除数据库数据

## 3) 客服聊天操作

- 支持文本/图片/语音消息
- 支持表情面板输入
- 对方输入时显示 `对方正在输入…`

## 4) 常见问题

- 导入成功但列表无订单
  - 先检查是否在“已隐藏”视图
- 订单号不匹配（`Order not found`）
  - 检查是否连到错误环境/数据库
  - 检查订单号是否被 Excel 科学计数法改写
- 轨迹地图加载慢
  - 后台使用 OSM，部分网络环境会有延迟

## 5) 日常检查建议

- 正式导入前先执行 `导入预检(Dry-run)`
- 失败项导出后修正再导入
- 大批量操作后抽样核对状态与物流字段
- 聊天页面检查 `对方正在输入…` 是否能正常显示与消失
