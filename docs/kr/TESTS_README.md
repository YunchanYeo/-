# 테스트 전략

언어 / 语言:
- 한국어: `tests/README.md`
- 中文: `tests/README.zh-CN.md`

이 디렉터리는 프로젝트 공통 테스트 정책의 진입점입니다.

- `backend/tests`: API/서비스 단위 및 통합 테스트(Vitest)
- `admin-web/tests`: React 관리자 웹 테스트(확장 예정)
- `frontend/tests`: 미니프로그램 로직 테스트(확장 예정)

공통 규칙:

- 새 기능은 가능하면 해당 영역 테스트 폴더에 자동화 테스트 파일을 최소 1개 추가합니다.
- 버그 수정은 재발 방지 회귀 테스트를 함께 추가하는 것을 원칙으로 합니다.
