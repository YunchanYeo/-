# 사용자 운영 가이드 (KR)

## 1) 대상

- 운영자/CS/관리자 화면 사용자
- 코드 수정 없이 화면에서 수행하는 작업 기준

## 2) 관리자 웹 주요 업무

### 주문/발송 처리

- `订单与发货`에서 주문 상태 변경
- 운송장 정보 입력 및 물류 트레이스 확인

### Excel 일괄 처리

- `导出 Excel`: 주문 데이터 다운로드
- `导入 Excel`: 주문 상태/물류 일괄 반영
- `导入预检(Dry-run)`: 실제 반영 전 사전 검증
- `重试失败项`: 실패 항목만 재시도
- `导出失败项Excel`: 실패 목록 다운로드

### 주문 숨김/복구 (관리자 화면 전용)

- 다중 선택 후 `选中隐藏` / `选中恢复`
- `查看已隐藏`, `恢复全部`
- 주의: 사용자 주문/DB를 삭제하지 않으며, 관리자 화면 표시만 제어

## 3) 고객센터 채팅 운영

- 미니/관리자 모두 텍스트·이미지·음성 지원
- 이모지 패널로 빠른 입력 가능
- 상대방 입력 중일 때 `对方正在输入…` 표시

## 4) 자주 발생하는 이슈

- 导入 성공 로그가 있는데 목록에 안 보임
  - `查看已隐藏` 상태인지 확인
- 주문번호 불일치 (`Order not found`)
  - 환경(DB) 혼선 여부 확인
  - Excel 과학표기법으로 주문번호 변형 여부 확인
- 물류 지도 지연
  - 관리자 웹은 OSM 타일 사용(중국 네트워크 환경에 따라 지연 가능)

## 5) 운영 체크리스트

- 대량导入 전 `导入预检(Dry-run)` 수행
- 실패 항목은 내보내기 후 수정 재업로드
- 처리 후 샘플 주문의 상태/운송장 반영 확인
- 채팅 확인 시 `对方正在输入…` 표시가 비정상적으로 오래 남는지 점검
